# Security Policy

## Reporting Security Issues

e-invoice.be maintains this SDK. We take security seriously, and we encourage you to report any security vulnerability promptly so that we can take appropriate action.

To report a security issue in this SDK or in the e-invoice.be services, send an email to security@e-invoice.be. Do not open a public GitHub issue.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us keep this SDK and our services secure.
If you believe you have found a security vulnerability, please adhere to responsible disclosure practices by allowing
us a reasonable amount of time to investigate and address the issue before making any information public.

---

Thank you for helping us keep the SDK and the systems it interacts with secure.
